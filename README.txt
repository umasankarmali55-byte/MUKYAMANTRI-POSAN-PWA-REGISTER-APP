Mukhyamantri Posan Register - PWA App Pack (v6)
===================================================

Included Files:
- index.html             (Complete app with Install App button, Offline badge, JSON Backup/Restore, PDF & Excel export)
- manifest.webmanifest   (PWA manifest)
- sw.js                  (Offline Service Worker - posan-v6)
- _headers               (Cloudflare Pages / Netlify headers)
- netlify.toml           (Netlify headers config)
- icons/                 (192x192, 512x512, maskable-512, apple-touch-icon)

Deploy on Cloudflare Pages (Direct Upload):
1. Go to Cloudflare Dashboard -> Workers & Pages -> Create -> Pages -> Upload assets.
2. Upload this folder or the zip file (mukhyamantri-posan-pwa-pack.zip).
3. Deploy! Your HTTPS URL is ready immediately.

Install as App:
- Android / Desktop (Chrome or Edge): Tap the "Install App" button in the sidebar or mobile header.
- iPhone / iPad (Safari): Tap Share -> Add to Home Screen.

Data Backup:
- Go to Settings -> "Data Backup & Restore" to export or import a .json backup across devices.
